# Le Répertoire — Design System

A hospitality business and venue management platform. Combines traditional ops (payroll, compliance, HR) with modern AI capabilities into a single operational hub for multi-venue restaurant operators.

## Status

Working from the product brief while waiting for the codebase / Figma source. Tokens and components below are a v0 — they will be reconciled against the real source once provided.

## Surfaces

- Web app (desktop) — primary
- Mobile web / responsive

## Direction

- **Vibe:** clean, modern, professional. Cool palette (slates, deep greens, ink) with dark mode.
- **Type:** exploring two pairings — serif display + sans body, and all-sans with weight contrast.
- **Density:** comfortable default, with compact mode for data-heavy ops screens.

## Files

- `tokens/colors.css` — color tokens (light + dark)
- `tokens/typography.css` — type pairings
- `tokens/spacing.css` — spacing, radius, shadow, motion
- `components/` — buttons, inputs, nav, cards, tables, modals, content blocks
- `variations/` — 2 directional showcases
- `screens/` — demo screens (dashboard, content, mobile)
- `index.html` — entry, links everything

## Principles

1. **Operational clarity over decoration.** Owners run the business in this app — every chrome element earns its space.
2. **One quiet system, two voices.** A neutral surface that lets data and content lead, with a single confident accent.
3. **Read like a kitchen ticket.** Information density is OK; rhythm and hierarchy make it scannable.
4. **AI is a teammate, not a takeover.** Maestro / AI surfaces feel additive — never block the existing workflow.
