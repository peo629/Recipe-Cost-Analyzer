### ✅ Developer Notes

#### **Business Context**

* A venue can exist:

  * As a **single-venue entity** (e.g., independent restaurant)
  * As part of a **multi-venue parent company** (e.g., Melbourne Venue Co)
  * As a **multi-work-area site** (e.g., hotels, stadiums)

#### **Collection Relationships**

* `company_id` → references `business_entities.company_id`
* `work_area_id` → shared mapping key across venues and `business_users`
* `employees[].linking_id` → references `business_users.linking_id`

#### **Recommended Indexes**

```js
db.business_venues.createIndex({ venue_id: 1 }, { unique: true });
db.business_venues.createIndex({ company_id: 1 });
db.business_venues.createIndex({ "workareas.work_area_id": 1 });
db.business_venues.createIndex({ "workareas.employees.linking_id": 1 });
```
